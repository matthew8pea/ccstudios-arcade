Galactic Legends mouse pointers for Windows
==========================================

Every Windows pointer, traced from the Windows Aero set and recoloured in the
game's cyan-on-navy style with a glow, scaled up 20% around the tip so each
pointer's click point sits exactly where the Windows one does.

INSTALL
1. Right-click "Galactic Legends.inf" and choose Install.
   (Windows 11: pick "Show more options" first if Install is not in the menu.)
   Say Yes to the admin prompt. This copies the pointers to
   C:\Windows\Cursors\Galactic Legends and registers the scheme.
2. Open Settings > Bluetooth & devices > Mouse > Additional mouse settings,
   go to the Pointers tab, choose "Galactic Legends" in the Scheme list, and press OK.

To go back, pick "Windows Default" in the same Scheme list.

WHAT IS IN HERE
  arrow.cur     Normal select           help.cur      Help select
  working.ani   Working in background   busy.ani      Busy
  cross.cur     Precision select        text.cur      Text select
  pen.cur       Handwriting             no.cur        Unavailable
  ns.cur        Vertical resize         ew.cur        Horizontal resize
  nwse.cur      Diagonal resize 1       nesw.cur      Diagonal resize 2
  move.cur      Move                    up.cur        Alternate select
  link.cur      Link select             pin.cur       Location select
  person.cur    Person select

Each file holds the five sizes Windows uses (32, 48, 64, 96 and 128 px), so
the pointers stay sharp at any display scale and pointer size setting.
